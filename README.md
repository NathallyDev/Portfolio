# 🌐 Personal Portfolio  

### Description  

This is my personal portfolio website, showcasing everything about me as a developer. It includes sections about who I am, the technologies I work with, my resume, social media links, contact information, and examples of my projects.  

The website is designed to be responsive and user-friendly, providing a seamless experience for visitors.  

---

### 🛠️ Technologies Used  

- **Development Tools**:  
  - Visual Studio.  
- **Languages and Frameworks**:  
  - HTML, CSS, JavaScript, and PHP.  

---

### 📂 Website Structure  

The portfolio consists of four main pages:  
1. **Home**:  
   - A welcoming page introducing myself and my key skills.  
2. **About Me**:  
   - Details about who I am, what I do, and the programming languages I specialize in.  
   - Includes a downloadable version of my resume.  
3. **Projects**:  
   - Showcases my work with links to project repositories and live demos.  
4. **Contact**:  
   - A section with my social media links and a contact form for visitors to reach out.
